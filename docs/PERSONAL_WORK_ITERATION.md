# Personal and work screen-time iteration

Started 9 November 2026 at 18:44 UTC. User requested a sustained category-by-category improvement pass and a second refinement/reassessment pass. Timing below records actual work and tests; no category is assigned invented elapsed minutes.

## Product direction

Screen time across all computer use comes first. Personal use is legitimate use, not a synonym for excluded/private data or failed work. Activity type, personal/work context, captured evidence and financial entries are separate concepts. Keep Today, Past days and Settings and the four-step clickable setup. TypeSafe provides typed category decisions under existing explicit consent; local screen-time insights must work without AI or a key.

## Implementation sequence

1. Build a local, interval-based screen-time/weekly-insight layer and explicit local Personal/Work context, independent of billing and outgoing AI data.
2. Extend optional ready-made app-activity categories for games, media, browsing and computer utilities without replacing old tasks or silently widening consent.
3. Strengthen background recovery, memory/uncertainty handling, diagnostics, evaluation and privacy controls against personal/work and time-boundary cases.
4. Improve simple navigation, accessible controls, local exports and explanation/correction flow.
5. Perform independent second-pass adversarial review, substantive sustained synthetic testing, final UI/core checks and honest 28-category reassessment.
